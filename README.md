# Sistem Informasi Posyandu Tumbie

## Deskripsi
Sistem Informasi Posyandu Tumbie merupakan aplikasi berbasis web yang dikembangkan untuk mendukung pengelolaan data Posyandu.

## Teknologi
- Node.js
- JavaScript
- SQL Database
